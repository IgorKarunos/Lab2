# Лабораторная работа 2: Вычисление информационной энтропии файла

## Описание
Программа для анализа информационной энтропии файлов по формуле Шеннона:
H = -Σ p(x) * log₂(p(x))

## Функциональность
1. **Анализ частот символов** в файле (байты 0-255)
2. **Вычисление энтропии** по формуле Шеннона
3. **Генерация тестовых файлов** различных типов для проверки

## Результаты тестирования

| Тип файла | Энтропия | Теоретическое значение |
|-----------|----------|------------------------|
| Идентичные символы | 0.0 | H = 0 (нет неопределённости) |
| Бинарный (0/1) | ≈1.0 | H = log₂(2) = 1 бит |
| Случайные (0-255) | ≈8.0 | H = log₂(256) = 8 бит |
| Английский текст | ≈4.3 | H ≈ 4-4.5 бита (избыточность) |

## Технологии
- Java 17
- Spring Boot 4.0.6
